# Security Research Website

Next.js + TypeScript + Tailwind + MDX cybersecurity research site.

## Run

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Add a blog post

Create:

```text
content/posts/<category>/<slug>.mdx
```

Add frontmatter and write the article. No React registration is required.

## Routes

- `/`
- `/portfolio`
- `/blog`
- `/blog/<slug>`
- `/category/<category>`
- `/sign-in`
